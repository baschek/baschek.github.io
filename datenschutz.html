Datenschutzerklärung für TESS

TESS ist eine private Anwendung, die nur ihr Betreiber für sein eigenes Google-Konto nutzt. Andere Personen nutzen TESS nicht.

Welche Daten

Mit Zustimmung des Betreibers liest TESS über die Google Calendar API seine Kalenderliste und seine Termine und legt auf seine Anweisung Termine an, ändert oder löscht sie.

Wo und wie lange

Die Daten werden ausschließlich auf einem privaten Server des Betreibers gespeichert, nur so lange, wie er sie für seine eigene Planung braucht. Sie werden nicht verkauft, nicht an Dritte weitergegeben und nicht für Werbung verwendet.

Google-API-Daten

Die Nutzung von Daten aus Google-APIs hält sich an die Google API Services User Data Policy, einschließlich der Limited-Use-Anforderungen.

Widerruf

Der Zugriff kann jederzeit unter myaccount.google.com/permissions entzogen werden; danach löscht der Betreiber das gespeicherte Zugangs-Token.
